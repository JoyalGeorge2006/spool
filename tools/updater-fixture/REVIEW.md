## v3 timeout and replacement-runner controls
Every subprocess starts a separate process group. Timeout kills the group, waits at most five seconds to reap, saves partial output and status124, and aborts later cases without retry. The device case's finally block retains evidence even on timeout. The replacement's code/name/cert/hash metadata is recorded before runner recovery. Test APK hash is pinned at build. Missing test package or runner permits one reinstall of that exact test APK only; the host never reinstalls58, clears app data or resets the sentinel during replacement verification.
